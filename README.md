# MAJORNEXO

Portfólio de desenvolvimento web, manutenção técnica e vendas.

Site: https://majornexo.nexos.log.br
Instagram: https://www.instagram.com/majornexo/

## Executar localmente

Requer Node.js compatível com o Vite registrado no package-lock.json.

```sh
npm ci
npm run dev
```

Para compilar: `npm run build`.

## Conteúdo desta cópia pública

React, Vite e Three.js; identidade tridimensional animada; fundo Ember Storm pelo pacote ThreeUI; galeria e navegação do portfólio.

Vídeos de demonstração, configurações da hospedagem, credenciais, capturas de desenvolvimento e arquivos operacionais não integram esta cópia. O vídeo de demonstração DaCruz usado no site publicado deve ser fornecido separadamente em `public/projects/dacruz/tour.mp4` para reproduzir toda a experiência local.

Fotos e marcas do portfólio conservam os direitos de seus titulares. A visibilidade deste repositório não concede licença de redistribuição das imagens ou do código de terceiros. Dependências mantêm suas licenças próprias.
